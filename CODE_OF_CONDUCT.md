# Code of Conduct

## Our Pledge

We are committed to providing a welcoming and inclusive environment for all contributors and users, regardless of background, identity, experience level, or any other characteristic. We welcome contributions from everyone and are dedicated to building a community that respects all people.

## Our Standards

Examples of behavior that contributes to creating a positive environment include:

- **Being respectful and inclusive** - Use welcoming and inclusive language
- **Being constructive** - Provide constructive feedback and accept criticism gracefully
- **Focusing on what is best for the community** - Collaborate and communicate openly
- **Showing empathy** - Be mindful of other people's experiences and perspectives
- **Supporting learning** - Help others learn and grow, especially in technical discussions

Examples of unacceptable behavior include:

- Harassment, discrimination, or unwelcome comments related to any protected characteristic
- Personal attacks, trolling, or inflammatory comments
- Deliberate intimidation or threats
- Publishing others' private information without consent
- Any conduct that violates applicable laws or regulations

## Scope

This Code of Conduct applies to all spaces managed by the namforge/cpp project, including:

- GitHub repository (issues, pull requests, discussions, and comments)
- Project documentation and wikis
- Any official community channels or events

This applies to all contributors, maintainers, and users of the project.

## Enforcement

Project maintainers have the right and responsibility to remove, edit, or reject contributions that are not aligned with this Code of Conduct. Maintainers who do not follow the Code of Conduct may be removed from the project team.

### Reporting

If you witness or experience behavior that violates this Code of Conduct, please report it by:

1. Opening a private issue with maintainers
2. Contacting project maintainers directly
3. Using GitHub's reporting features for inappropriate content

All reports will be reviewed and investigated promptly and fairly.

## Attribution

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1, and aims to foster a collaborative and respectful environment for C++ learning and algorithmic exploration.

## Our Commitment

We are committed to fostering an open, welcoming, and supportive community where:

- Learning and experimentation with C++ and algorithms is encouraged
- AI-assisted development practices are explored collaboratively
- Contributors of all skill levels are valued
- Mistakes are treated as learning opportunities
- Everyone feels safe to ask questions and contribute ideas

By participating in this project, you agree to abide by this Code of Conduct.
